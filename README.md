# Pedinophyceae-Biogeography

A biogeography study of Pedinophyceae using the EukBank 18S rRNA V4 metabarcoding database.

This project investigates the global distribution, habitat preferences, and ecological drivers of Pedinophyceae — a class of small green algae — using publicly available metabarcoding data from EukBank. Analyses cover relative abundance, size fraction distribution, ocean layer stratification, and latitudinal/thermal niche patterns.

## Data pipeline

Scripts should be run in the following order:

1. **`R/utils/algae_data_preparation.R`**  
   - Reads raw EukBank sample metadata and joins with Longhurst province assignments  
   - Categorises samples by habitat, size fraction, salinity, and ocean layer (sunlit/dark, photic/twilight/aphotic)  
   - Subsets the full EukBank abundance table to target Pedinophyceae ASVs  
   - Calculates relative abundance using total reads per sample from the metadata  
   - Filters ASVs present in ≤ 2 samples  
   - Outputs `pedino_abundance.csv`, `pedinos_filtered_abundance.csv`, `pedinos_samples_edited.csv`

2. **`R/utils/dino_data_preparation.R`** *(optional, for comparative analyses)*  
   - Subsets EukBank to dinoflagellate ASVs using the taxonomy table  
   - Produces sample-level presence/absence and rarefied ASV richness  
   - Outputs `dino_presence.csv`, `dino_richness_rarefied.csv`

3. **`R/01_abundance_mapping.R`**  
   - Plots a global world map of Pedinophyceae relative abundance per sample

4. **`R/02_sizefraction_overlap.R`**  
   - Analyses read abundance and ASV overlap across size fractions (Pico, Nano, Micro)  
   - Produces violin plots, UpSet plots, and ternary plots  
   - Runs PERMANOVA on community composition by size fraction

5. **`R/03_ocean_layer.R`**  
   - Compares Pedinophyceae abundance between sunlit and dark ocean layers  
   - Produces violin plots and UpSet plots by ocean layer  
   - Runs Wilcoxon tests per size fraction

6. **`R/04_geographical_distribution.R`**  
   - Analyses latitudinal occupancy patterns per size fraction  
   - Tests latitude and temperature as predictors of presence using permutation-based logistic regression  
   - Calculates abundance-weighted thermal niche breadth (Levins index)
